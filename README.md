# 📊 Dashboard de Vendas do Xbox com Excel

Desafio prático desenvolvido como parte do **Bootcamp Santander - Excel com IA**.

## 📌 Sobre o Projeto
Este projeto consiste na construção de um dashboard intuitivo e interativo no Microsoft Excel para análise do desempenho de vendas de assinaturas e serviços do Xbox (EA Play, Minecraft Season Pass e Xbox Game Pass).

## 🛠️ Funcionalidades e Análises
- **Cards de Indicadores (KPIs):** Visualização clara do total de assinaturas da EA Play e Minecraft.
- **Gráfico de Desempenho:** Análise comparativa do total de assinaturas do Xbox Game Pass.
- **Filtros Dinâmicos (Slicers):** Segmentação de dados por tipo de assinatura (Anual, Mensal, Trimestral) para análise personalizada.
- **Design e Navegação:** Layout moderno e organizado focado em facilitadores de tomada de decisão.
